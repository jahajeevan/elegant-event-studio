# Elegant Event Studio

A polished event-studio website showcasing weddings, birthdays, corporate events, engagements, and other bespoke celebrations.

## Highlights

- Service, gallery, story, and contact pages
- Responsive, motion-led visual design
- Component-based React architecture

## Technology

React, TypeScript, TanStack Start, Vite, Tailwind CSS, and Framer Motion.

## Run locally

```bash
bun install
bun run dev
```

Create a production build with `bun run build`.
